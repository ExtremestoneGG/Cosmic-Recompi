# Roadmap

The immediate delivery is a portable ISO-import/launcher flow, original-game video settings and return to launcher, followed by documentation and a test release. Ambient-video support is prepared; the final recording is still to be supplied.

After that delivery, resume Direct3D 12 optimization toward **stable 60 game FPS with consistent frame time**, while preserving native-or-higher resolution and graphical integrity. Maintain the accepted optimization stack and saved scene measurements. Camera stability above 30 FPS remains part of that work, not a completed feature.

Broader campaign/crash/save coverage and additional hardware testing are necessary before calling the game complete. Do not substitute a translation percentage or an average-FPS screenshot for compatibility validation.

Achievements UI, Mods, Players, uncapped mode, Vulkan tuning and a full game translation are deferred. The original game interface remains English. No date or completion percentage is promised without evidence.
